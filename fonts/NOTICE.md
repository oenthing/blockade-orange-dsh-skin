# Bundled fonts

## Borda (400 / 500 / 600 / 700)

`borda-*.woff2` — **Borda**, the typeface specified by Ubisoft's *The Division*
UI style guide.

- Rights holder: Northern Block (commercial license, not free)
- Source: files supplied by the user of this profile for local, private use
- These subsetted WOFF2 builds are embedded in `client.js` **for this local
  profile only** and must not be shipped in a published or shared package.
- If you publish this theme, remove the Borda faces and keep Titillium Web.
